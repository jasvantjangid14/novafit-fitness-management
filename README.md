# NovaFit-Fitness-Managenment

A responsive Fitness Management Website designed to provide gym information and membership plans.

# Features

- Home Page
- About Us
- Membership Plans
- User Login & Signup Pages
- Contact Page
- Responsive Design

# Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript

# Project Structure

- "index.html" – Home Page
- "about.html" – About Page
- "membership.html" – Membership Plans
- "login.html" – Login Page
- "signup.html" – Signup Page
- "contact.html" – Contact Page
